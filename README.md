# Data Structures &amp; Algorithms 2 CA1 Project

# Project Objective:
Create a JavaFX application that allows users to load and view images (JPEG, GIF, etc.)

# Required Feature List:
- GUI list
- File chooser
- Onscreen image - Display the image onscreen
- Grayscale image - Option to
- Image details - size, file name
- Colour channel window - individual windows showing the images red, blue and green colour channels with a menu to display each window
- Image adjustment controls - Controls to adjust hue, saturation and brightness

Grade: 100%
